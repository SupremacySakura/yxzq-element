# super-table 范围:基础集

`super-table` 锁定为**基础集**:渲染行列 + slot 自定义单元格 + 空态/加载态 + 排序 + 选择。明确**不做**:固定列、展开行、虚拟滚动、树形数据、合计行、单元格合并、列拖拽。

## Considered Options

- **极简(仅渲染 + slot)**:拒绝。排序与选择是表格的最小可用集。
- **中等(含固定列/展开行)**:拒绝。手绘风视觉表达不直观,且实现成本极高。
- **完整(对标 Element Plus)**:拒绝。约 50 个 API,违背 ADR-0001 的范围约束。

## Consequences

- 后续任何"加固定列"的请求都需要新的 ADR,并明确破坏性变更成本。
- `super-table` 的实现工作量约 4–5 天(其他组件 1.5–2.5 天)。
